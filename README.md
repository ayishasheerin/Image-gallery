# Wonders of the World – Dynamic Image Gallery

## Project Description

This project is a dynamic image gallery created using React. It displays the New Seven Wonders of the World with images, titles, locations, and short descriptions.

The gallery uses reusable React components and an array of objects to display the information dynamically.

## Features

- Displays all seven wonders of the world
- Reusable `ImageCard` component
- Dynamic rendering using the `map()` method
- Passes information to components using props
- Local image imports
- Responsive layout for desktop, tablet, and mobile screens
- Hover effects on image cards
- Clean and elegant user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- React.js
